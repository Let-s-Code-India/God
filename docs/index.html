FIRST RUN

A small surface area.
A lot of leverage.

Import only the library you need, or bring the whole toolkit into one workflow. Every public member has an offline-friendly example so you can explore before adding a provider key.

from godai import aura, nexus, aether, apex

@aura.heal(retries=1)
def add(left: int, right: int) -> int:
    return left + right

print(add(2, 3))

INSTALLATION

Ready in one clean environment.

Use a virtual environment on desktop Linux, macOS, and Windows. For Android, use Ubuntu inside proot-distro.

01

Desktop

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install godai
02

Termux / Android

pkg install proot-distro
proot-distro install ubuntu
proot-distro login ubuntu
apt update
apt install -y python3 python3-pip python3-venv
python3 -m venv godenv
source godenv/bin/activate
pip install godai

TROUBLESHOOTING

When the environment gets in the way.

These are installation issues observed with this dependency stack and the practical route around each one.

Termux: pydantic-core / Rust

Android wheels may be unavailable, so pip falls back to a Rust and maturin build and reports unsupported architecture or missing cargo.

pkg install proot-distro
proot-distro install ubuntu
proot-distro login ubuntu
apt install -y python3 python3-pip python3-venv
python3 -m venv godenv && source godenv/bin/activate
pip install godai

iSH and iPadOS terminals

iSH is Alpine/musl and commonly runs under x86 emulation. A compatible pydantic-core wheel and usable Rust toolchain may not exist.

Use Ubuntu in proot-distro, a Linux VM, or a cloud workspace such as Codespaces instead of a direct iSH install.

PEP 668

Debian and Ubuntu may reject system-wide pip writes with externally-managed-environment.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install godai

Keep the distribution marker intact. --break-system-packages is a last resort.

Alpine, musl, or no wheel

musl-based systems, emulated CPUs, and unusual Python versions can force native builds for pydantic-core. Upgrade pip, use CPython 3.10+, and prefer glibc-based Ubuntu with a matching wheel.

python -m pip install --upgrade pip setuptools wheel
python -m pip install godai

TLS or certificate failures

SSLCertVerificationError usually means the OS or corporate proxy lacks a trusted CA. Update CA certificates or configure the organization’s CA bundle. Do not disable TLS verification.

Dependency resolution conflicts

Start from a fresh virtual environment, upgrade pip, and inspect the first conflicting requirement. Avoid mixing global packages into the install.
